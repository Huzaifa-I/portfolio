# Huzaifa Islam · Product Portfolio

The personal portfolio of Huzaifa Islam, Product Manager in payments and fintech. It holds case studies, interactive prototypes and narrated walkthrough videos.

**Live site:** _add your Render URL here_

## What's inside

| Path | Contents |
|---|---|
| `index.html` | The portfolio site |
| `portfolio.html` | The case studies as a printable document (also `Huzaifa-Islam-PM-Portfolio.pdf`) |
| `prototypes/` | Self-contained HTML prototypes that open in any browser |
| `videos/` | Narrated walkthroughs (`.mp4`) with caption files (`.srt`) |
| `downloads/` | Source code for the provider 3DS simulators (Node 18+, no dependencies) |

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

## About the data

The prototypes use a neutral demo brand (Acme Pay) with sample and mock data. They contain no customer data, credentials or company figures. The simulators ship with placeholder keys only.
